# Agents' Last Exam task data archive

This registry entry pins the gated Hugging Face archive used by the official
[Agents' Last Exam](https://github.com/rdi-berkeley/agents-last-exam) runner.
The archive contains task `input/`, optional `software/`, and hidden
`reference/` trees. It must not be exposed to an agent during its evaluation.

The pinned archive revision is
`95e419efaae5fd3874b709f7ef63c357aa29379c`. The archive's own card identifies
the source revisions for the task code, inputs, and references. Access requires
Hugging Face approval and the archive terms prohibit training, evaluation-time
leakage, and redistribution.

The archive is not copied into this repository. Download it only through the
official instructions after access is approved. Task-level inputs can contain
realistic professional records and software artifacts; review the selected
task's card and license before any external use. The metadata does not declare
intentional PII, but it is not a substitute for a task-specific privacy audit.
