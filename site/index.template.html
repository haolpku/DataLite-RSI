01Overview

What if the next improvement comes from better data decisions? DataLite-RSI invites the community to explore how recursive feedback can make compact training sets more useful. Our initial experiments are a starting point; new methods, tasks, and findings will help shape this research direction.

  • Choose what matters. Select useful examples from a fixed pool using model feedback.
  • Learn how to generate. Evolve synthesis policies from accepted examples and failure cases.
  • Improve the process. Refine the program that turns source data into a training set.
