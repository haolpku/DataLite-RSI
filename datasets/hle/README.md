# HLE Dataset

This registry entry points to the full Humanity's Last Exam dataset on
Hugging Face at immutable revision
`5a81a4c7271a2a2a312b9a690f0c2fde837e4c29`. The evaluator consumes a
runtime-mounted export or an authorized Hugging Face request and does not copy
the dataset into GitHub or the agent sandbox image.

The dataset is gated, has 2,500 test items, includes text and image fields,
and is distributed under the MIT license. Access approval and contamination
risk must be recorded before a verified benchmark result is submitted.
