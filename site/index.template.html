01Overview

Evolve the program that produces the data. Supply a fixed corpus, output requirements, quality criteria, and feedback sources. DataFlow-RSI turns this evidence into executable changes to generation, verification, selection, and pipeline structure.

  • Specify useful supervision. Define the task, output schema, and evidence for judging the data.
  • Revise executable pipelines. Let the agent author operators and coordinate changes across stages.
  • Retain reusable improvements. Carry task feedback, execution evidence, and program history into the next revision.

02DataLite-RSI

Research highlight · Data efficiency

When can less training data be more useful?

DataLite-RSI is a research direction within DataFlow-RSI. It explores data-efficient recursive self-improvement through selection, synthesis, and reusable production strategies. Less is More for RSI is the question behind the reference experiments below.
