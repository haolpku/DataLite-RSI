# Minerva Math

272 science and mathematics problems from MIT course materials requiring
multi-step quantitative reasoning.

**Source:** Qwen2.5-Math evaluation harness, `https://github.com/QwenLM/Qwen2.5-Math/tree/a45202bd16f1ec06f433442dc1152d0074773465/evaluation/data`.
Problem text verified identical to
[math-ai/minervamath](https://huggingface.co/datasets/math-ai/minervamath)
(sha `ee46ddc498933b1977577953250ca5c66be64f96`; field `question` there
vs `problem` in the harness).

**Metric:** accuracy, greedy decoding.
